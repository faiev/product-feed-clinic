# Publish with GitHub Pages

This is a static HTML/CSS/JavaScript site. No build command, server, database, environment variables or paid hosting are required.

## Enable publishing

1. Open the repository: https://github.com/faiev/product-feed-clinic
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**.
5. Click **Save**.

GitHub will build and publish the site. The public URL should be:

https://faiev.github.io/product-feed-clinic/

The first deployment may take a few minutes. Check the Pages panel for the deployment status and exact URL.

The root contains only the site, the local-only checker, synthetic demo data, and documentation. No account passwords, customer data or merchant exports are included.
